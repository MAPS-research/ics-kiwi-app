## 操作困难与未测边界

- 浏览器连接器不可用，因此采用真实 Chrome 原生操作。DevTools 设备模拟中的部分 AX 点击没有命中，改用当时截图定位；最后确认实际页面状态，未把点击尝试当作成功。
- 实施期间 HMR 刷新导致 R console 的瞬时输出重置；输出已先前实际观察并截图，代码与数据库记录仍在。验收结论以刷新后的稳定页面和持久化历史为准。
- DevTools 的 Fit to window 与页面缩放曾造成视觉预览和页面捕获比例不一致；用页面缩放重置到 100% 后复核了 320px 内容与横向导航。没有把这个预览状态作为产品布局缺陷。
- Console 中见到 Grammarly/Zotero 扩展来源的报错、Vite 日志，以及 webR 的 PostMessage/嵌套 REPL 限制提示。已观察到 R 正常执行；这些信息没有作为产品失败。
- **未实测真实 Kiwi**：官方 iframe handshake/context、显式 app token 获取、真实 RS256/JWKS 与 app/class/expiry 校验、真实教师 UUID grant 拒绝/通过、已批准 contextual-chat prompt 与 scopes、host 导航、宿主 chat 不能关闭的实际表现、注册/whitelist/enable/deployment。实现代理的契约/安全测试属于另一个证据层。
- **未实测在线 AI**：本轮练习都是本地模板，Ask Kiwi 都是固定本地指导；没有真实模型生成结果。不能把本地回退成功称为真实 AI 成功。
- 没有迁移或操作真实用户数据；旧作业/成绩在生产环境的保留不由这个空白隔离库实验证明。此轮 Review 记录在服务重启、页面刷新与来源修复后仍可见。
- 未测所有题型、文件/研究导出、所有筛选组合、其他浏览器、实体手机、键盘/屏幕阅读器全流程、断网恢复或多教师并发；这些不应列为本轮通过项。
