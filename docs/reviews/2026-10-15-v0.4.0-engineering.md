## Synthetic query benchmark

Command: `python3 scripts/benchmark-analytics.py --sessions 100000`.

Fixture: 100,000 synthetic session rollup rows, 5,000 students, 200 question identities, four chapters, temporary SQLite database. Three query timings per view; median reported. It did **not** populate a realistic event/chat payload corpus or measure browser rendering, HTTP concurrency, real classrooms, ingestion throughput, or AI capacity. The assignments fixture contained no assignment IDs and therefore returned zero assignment rows.
