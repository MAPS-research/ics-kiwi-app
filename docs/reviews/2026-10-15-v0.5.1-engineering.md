# v0.5.1 teacher-entry engineering verification

Date: 2026-10-15 PDT. Implementation-side checks, separate from the [independent review](2026-10-15-v0.5.1.md).

## Result and scope

Teacher password sign-in and normal app-token exchange succeeded through the running Kiwi APIs. The confirmed entry defect was the global teacher link's missing course: `/admin/app/ics-r-lab` could mount a course-only Lab without a course identity. The new resolver selects the only enabled teaching course or asks the teacher to choose. Standalone teacher access now links primarily to Kiwi sign-in and clearly labels the separate local demo key.

The independent reviewer found three related defects: the actual instructor response contains Class objects despite a string-array client declaration; the outer instructor layout selected the first course before the resolver completed; and a previous lookup error could block a later valid course. All three were corrected and independently retested. The final implementation also suppresses outdated request writes and remounts the frame when its course changes. Initialization failure now stops the loading spinner and offers retry/return navigation.

This is a code/API/DOM fix. The exact entry path used by the reporting user has not been confirmed. Browser control became unavailable and then explicitly stopped; no further browser action or alternate automation was attempted. This version has no new visual screenshots or complete browser acceptance.
