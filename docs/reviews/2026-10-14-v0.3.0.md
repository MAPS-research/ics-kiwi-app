### 实际题目核对

1. 相似预测题 1：`scores <- c(5, NA, 9, 7); print(mean(scores))`。可见标题「非缺失均值」，题干问唯一输出；实际 webR 返回 `[1] NA`，输入 NA 正确。
2. 相似预测题 2：`scores <- c(4, NA, 10); print(mean(scores))`。标题「处理 NA 后计算平均值」；点击下一相似题后旧答案和反馈消失，实际 webR 返回 `[1] NA`，输入 NA 正确。
3. 自由补全难度 3：「缺失值均值与索引」，starter 为 `x <- c(10, NA, 6, 8, NA, 4); result <- mean(x[c(2, 4, 5)], na.rm = ____); print(result)`。填 TRUE 后实际 `[1] 8`，检查正确。
4. 自由选择难度 4：「缺失值与向量索引」，题目问 `mean(x[!is.na(x)][2:4])`，`x=c(2,NA,5,8,NA,10)`；选项 6、7.666667、8、NA。实际选择 7.666667 判对，解析正确。

## 5. 保留的问题与下版重点

- **P3 Markdown 阅读体验**：App解释回复与宿主历史详情仍可显示 literal `###`、反引号、`**` 和 fenced R代码；未溢出，但长回答难读。尚未实现/验收富文本渲染。
- **P3 生成题标题质量**：两题预测标题含「非缺失」「处理 NA 后」，而代码仍用默认 `mean()`，输出 NA。题干、代码和判定正确，标题可能误导，应做标题/技能一致性验证。
- 教师官方登录后仍需第二次 App 本地密钥；它与本地 SQLite 成绩/遥测服务独立。当前本地演示可使用，不应称为生产角色权限/SSO 已统一。
- 本次给 AI 的课程材料是明确标注的 **demo课程摘要**（宿主 `CSS-demo-course-context.pdf` 与course prompt），没有验证完整用户所给 CSS 材料解析与检索，更没有声称全量 syllabus/assignments自动入库。
- 未覆盖复杂 R绘图、大型依赖包安装、课程附件/数据集上传、多人并发、全浏览器或所有设备宽度。OpenAI输出四个真实任务样本通过，不意味着所有题型和所有难度组合质量均已验证。
- 下一版仍须独立 reviewer模拟学生/教师，优先重测真实流式鉴权、JSON约束/失败反馈、生成题质量及材料依据，同时反馈开发 agent 后再验证修复。
