# v0.6.0 independent browser review (teacher + student)

- **Version tested:** package `0.6.0` (`/api/health` → `"version": "0.6.0"`, `aiAvailable: true`), branch `codex/css-lab-v0.5.1`, uncommitted working tree as of 2026-10-22 23:10 PDT.
- **Reviewer:** independent review agent (did not implement v0.6.0). Spec: `docs/architecture-v0.6.0.md`; rulings: `docs/handoff/v0.6.0-decisions.md` (D1–D7); checklist: the v0.6 fix list (F*, DA*, TR*, FD*, LY*, NM*, TH*, Home wireframe).
- **Environment:** scratch API `KIWI_API_PORT=8500` on a `.backup` copy of `data/kiwi-lab.sqlite3` (scratchpad `v06/browser2/review.sqlite3`), Vite on 8501, live AI tutor from the local `.env` (`gpt-5.4-mini`). Standalone demo class `local-r-class`. Teacher at `http://127.0.0.1:8501`, student and researcher at `http://localhost:8501` (separate browser storage). Viewports 1280×860 and 390×844 in the built-in browser.
- **Data safety:** `data/kiwi-lab.sqlite3` was never opened for writing (mtime `Oct 22 00:39`, 503 808 bytes, unchanged). Ports 3000/3001/8100/8101 kept their original processes. Both scratch servers were stopped at the end. Everything the review created lives only in the scratch copy and is named `Review-v0.6.0-*`.

## Summary

The v0.6.0 teacher loop works end to end in a real browser: create → preview → publish homework with a past due date and a 7-day late window (D2), student late submission, hints-only Ask Kiwi that held against a direct request and an injection, per-question grading with rubric, auto-checked choice question, automatic late penalty, draft → release, gradebook states and links, full student × assignment timeline with AI provenance, researcher role with pseudonyms and consent filtering (D3), and the SOCS-SH 190 template (D4). No blocker was found.

**Eleven major findings** are confusing or misleading numbers and labels that a teacher or student would act on: students see an unexplained total after a late penalty, a graded question still shows "Needs review", the gradebook and the Results page disagree on in-class accuracy, assignment short labels collide (`HW0`), AI-generated questions show raw Markdown code fences, the AI-rules Compare view hides the change, researchers' per-type exports include unverified identities (D3 says they must not), the in-class exercise editor shows grading and late settings, the student assignment list files an open late-window homework under "Past due & closed", the AI-rules test panel mislabels a chosen homework question, and the grading-card actions change order between cards. A further 20 minor items are layout and polish issues.

Test suites run by the reviewer at the end: `python3 -m unittest discover -s server -p 'test_*.py'` → **450 tests OK (1 skipped)** with the AI keys blanked; `npx vitest run` → **46 files, 1 190 passed**; `npx tsc --noEmit -p tsconfig.json` → clean; `npx vite build --outDir <scratch>/dist` → built (only Vite's chunk-size warning).

### Difficulties

- The browser pane was hidden. After a page's first focus, neither switching tabs (`tabs_select`) nor clicking fired `focus` or `visibilitychange`. The re-check on return was therefore triggered with `window.dispatchEvent(new Event('focus'))` and `document.dispatchEvent(new Event('visibilitychange'))` on the real page.
