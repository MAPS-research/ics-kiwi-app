## Fixes after independent findings

- **Local sign-in:** both retained demo passwords mismatched their database hashes. The isolated-demo upgrade restored only the two known demo account password fields from the private credential file. Both subsequent real `/auth/login` calls succeeded, and both normal host app-token exchanges returned the correct user/course. Browser form sign-in is not retested.
- **Native R:** replaced fragile sink/error-swallowing output capture with the Lab's captured-stream runner and local webR assets. Run feedback waits for execution, duplicate Run clicks are disabled, and new records include language plus `captured-result-v1` outcome metadata. Historical results are not reclassified by guessing from text. Real R semantics and host type/build checks passed; browser success/error/correction retest is pending.
- **Demo PDF sidebar:** corrected the known demo material's category from `text` to Kiwi's `class materials`, preserving its PDF/chunks/content. This addresses the sidebar's category filter; its rendered list has not been retested.
- **Logout warning:** moved the logout state mutation into an effect and added explicit login navigation. Type/build checks passed; browser retest is pending.

The native maximum-update-depth console warning has not been isolated or retested. It remains an open finding, not a claimed fix.
