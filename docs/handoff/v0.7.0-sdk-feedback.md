## 优先反馈的 SDK / App API 能力

### SDK-01：按作业页面控制宿主聊天的可用性

- **使用场景：**教师关闭某个计分作业的 Ask Kiwi 后，希望当前 App 页面中的 Kiwi 自带聊天也关闭，离开作业后恢复。
- **旧版做法：**自创 `kiwi:setChatAvailability {available, reason}`，修改 `ClassAppView`、全局聊天状态和入口按钮。它关闭已打开的聊天，隐藏入口，并在页面卸载时恢复。
- **官方现状：**已有 `setChatDisplayMode`，支持 `modal`、`sidepanel`、`snap`、`fullscreen`；它会打开聊天，没有禁用或不可用状态。切换布局不能替代作业策略。
- **建议接口：**提供通用的、受教师/课程策略授权的可用性请求，明确作用范围、原因、执行回执、实际生效状态，以及离开页面/iframe 卸载后的恢复行为。接口名称由上游设计，不把旧的私有消息名称当成既定标准。
- **建议验收：**禁用期间当前宿主入口不能重新打开聊天；退出作用范围后正确恢复；拒绝未经授权的放宽策略；多个页面或窗口的作用范围有明确说明。该功能不应宣称能阻止用户访问其他 AI 工具。
- **v0.7 处理：**只控制 Lab 内 Ask Kiwi，准确提示 SDK 无法关闭宿主聊天。

证据：[官方宿主聊天布局处理](https://github.com/NYUSH-ML/kiwi-ui/blob/fbc29beab4c6063c07fcf273d89e7237fad850b7/src/pages/ClassAppView.tsx#L554)、[旧宿主补丁](https://github.com/MAPS-research/ics-kiwi-app/blob/3cdd34de9fbe3801353f75a1df1ef2952056b7bf/scripts/local-kiwi/frontend.mjs)。

### SDK-02：App 后端可验证的当前调用者课程权限

- **使用场景：**Lab 后端需要判断当前调用者能否发布作业、批改或查看教学分析。
- **旧版做法：**注入 `/api/kiwi-apps/ics-r-lab/lab/context`，查询 Kiwi 的课程成员和教师权限表，返回角色及 `canTeach`、`canManageCourse`、`canViewAnalytics`。其中同时返回邮箱的做法应撤回。
- **官方现状：**App token 已能验证调用者、App、课程和 scopes，但签名载荷没有课程角色。前端 context 或 query 中的角色不是 Lab 后端可独立信任的授权凭据；App 获得某个 scope 也不能直接解释成调用者有教师权限。
- **建议接口：**提供受签名保护的当前调用者课程角色/能力，或官方权限自省端点。绑定 `sub`、App 和课程，说明过期、撤销、课程成员变化及 TA 权限的含义；不返回其他用户的姓名、邮箱或名单。角色与 Lab 自己的操作权限映射应有明确契约。
- **建议验收：**学生不能通过篡改前端字段成为教师；不同课程的权限不能混用；撤销授权后的生效时间可验证；助教权限不是默认等同于课程管理员。
- **v0.7 处理：**使用 Lab 自己的显式课程/用户 UUID grant；没有 grant 就没有教师权限。

证据：[官方 App token 签发](https://github.com/NYUSH-ML/kiwi/blob/e31b21f2429330dab8b2a3b0897511c9c83d242c/src/kiwi-app/kiwi-app.service.ts#L910)、[旧 context/activity bridge](https://github.com/MAPS-research/ics-kiwi-app/blob/3cdd34de9fbe3801353f75a1df1ef2952056b7bf/scripts/local-kiwi/bridge/lab-bridge.controller.ts)。

### SDK-03：在 SDK 中正式暴露页面级辅导模式

- **使用场景：**App 页面希望请求“只给提示”的教学模式，并知道最终生效的策略。
- **旧版做法：**绕过 SDK，直接发送 `kiwi:updateContext {context, tutoringMode: "guidance"}`，并在 App 配置中设置 guidance。
- **官方现状：**宿主已经处理 `tutoringMode` 字段，但 SDK 0.2.0 的 `updateContext(text)` 只发送 context。这是 SDK 封装与宿主协议不一致，不是整套宿主能力缺失。
- **建议接口：**为 `updateContext` 提供有类型的选项，或单独提供策略请求；说明模式枚举、课程/管理员/页面策略的优先级，返回实际生效模式或拒绝原因。
- **建议验收：**不写自定义 postMessage 即可使用；课程策略不能被学生页面请求放宽；切换页面后不会沿用过期模式。
- **v0.7 处理：**只使用官方 `updateContext`，不再发送未封装的模式字段，也不声称 App 的规则能够覆盖宿主规则。

证据：[SDK updateContext](https://github.com/NYUSH-ML/kiwi-ui/blob/fbc29beab4c6063c07fcf273d89e7237fad850b7/public/sdk/v1/kiwi-app-sdk.js#L500)、[宿主 tutoringMode 处理](https://github.com/NYUSH-ML/kiwi-ui/blob/fbc29beab4c6063c07fcf273d89e7237fad850b7/src/pages/ClassAppView.tsx#L475)、[旧 Lab 消息发送](https://github.com/MAPS-research/ics-kiwi-app/blob/3cdd34de9fbe3801353f75a1df1ef2952056b7bf/src/lib/kiwi.ts#L69)。

## AI API 的扩展诉求

旧 Lab 直接调用 OpenAI，自行传入消息、模型参数并读取用量。这不是给 Kiwi SDK 增加了 AI 功能，而是绕过了 Kiwi；v0.7 已撤回该路径。以下需求应在 Kiwi 审批和调用边界内讨论。

| ID | 当前契约与影响 | 建议讨论 |
| --- | --- | --- |
| AI-01 较长代码和多轮任务上下文 | `contextual-chat` 的 `userMessage` 声明 `@MaxLength(8000)`。Lab 需要把规则、代码、问题和历史组装到这个字段，较长请求可能超限。 | 明确长度计数、上下文预算和超限错误；评估受批准的更大预算、会话或引用机制。保留平台配额，不以 App 直连供应商解决。 |
| AI-02 调用元数据 | 响应 DTO 包含 output、promptId、promptName、contextIncluded/contextOmitted，没有本次调用的模型、run ID 或 token 用量。旧直接调用路径曾记录 response ID 和用量。 | 返回当前 App 当前请求可见的 run ID、模型/配置版本、可提供的 token 用量和完成状态；未提供的值应为空，不推测。只开放本次调用的审计元数据，不返回其他用户或原始私有上下文。 |

**已有能力不要误报：**SDK 已有 `askAI` 和 `contextualChat`；contextual-chat 已有 `outputSchema`（根类型 object）。问题不是“没有 AI”或“没有结构化输出”。模型、推理参数和 provider 凭据继续由 Kiwi 管理；是否提供可选择的、管理员批准的任务配置，需要另外定义授权契约。

证据：[官方请求/响应 DTO](https://github.com/NYUSH-ML/kiwi/blob/e31b21f2429330dab8b2a3b0897511c9c83d242c/src/kiwi-app/dto/app-data.dto.ts#L124)、[旧 Lab provider adapter](https://github.com/MAPS-research/ics-kiwi-app/blob/3cdd34de9fbe3801353f75a1df1ef2952056b7bf/server/ai.py)。

## 应撤回或另行定义的旧做法

| 旧做法 | 反馈处理 / v0.7 边界 |
| --- | --- |
| 导出全班名单、姓名和邮箱映射 | 违反官方 “Apps never get identity”。不提出恢复 roster/user-lookup 的需求。使用 opaque UUID 和 App-local label。 |
| 直接 SQL 导出原始聊天、IDE、PDF、反馈和文件动作 | 不恢复 native-activity export。若跨工具教学分析仍是产品需求，先讨论 Kiwi 内的教师视图或经过审批的受控汇总；不能把数据边界当作漏写接口。 |
| CssLabLaunch / CssLabTeacherEntry | 已有通用 class-tab/class-admin-panel；不向宿主加入特定 App 的按钮、选课页或分支。导航问题按 HOST-01/02/03 处理。 |
| 替换 Kiwi 原生 WebR、复制 Lab runtime | Lab 使用自己的 webR；不要求宿主使用某个 App 的运行时。原生 IDE 的问题应另行复现后反馈。 |
| 改监听地址、SMTP、health、token TTL | 属于本地部署适配。旧 60 秒改 3600 秒修改的是宿主登录 access token；App token 本身默认一小时，SDK 已有重新获取 token 的机制。不要反馈成“SDK 不支持 token 刷新”。 |
| 为了教学策略而直连 OpenAI | 已撤回。使用 Kiwi 的已批准 prompt 与官方 API，服务失败不能偷偷切换 provider。 |

证据：[Kiwi 身份边界](https://github.com/NYUSH-ML/kiwi/blob/e31b21f2429330dab8b2a3b0897511c9c83d242c/CLAUDE.md#L67)、[通用入口与协议](https://github.com/NYUSH-ML/kiwi-ui/blob/fbc29beab4c6063c07fcf273d89e7237fad850b7/KIWI-APPS.md)、[SDK getToken](https://github.com/NYUSH-ML/kiwi-ui/blob/fbc29beab4c6063c07fcf273d89e7237fad850b7/public/sdk/v1/kiwi-app-sdk.js#L462)。
