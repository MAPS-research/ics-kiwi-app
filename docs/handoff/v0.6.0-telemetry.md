## Deviations

1. **Rejections raise.** `telemetry.add_event` raises `telemetry.EventRejected` (a `ValueError` carrying the `AddEventResult`) after logging `event_rejections`, because frozen `test_core` expects `ValueError` for an unknown type. Routes answer 422 `{status:"rejected", code, error, eventId}`; batches use `telemetry.ingest()`, which returns the result. Bad `eventId`/`sessionId`/`questionId` formats are per-event rejections (`invalid_payload`), not 400.
2. **Raw names.** Linked-class rows store `student_name=''` (§11.2). Standalone rows keep the v0.5.1 raw value (body name, else the session name): frozen FOUNDATION-08 asserts it. It is never used as a label.
3. **No DDL.** `OPS` stays empty: the frozen FOUNDATION-10 tests compare `applied_versions` with the core list only (ASSESS hit the same and reverted). Consequences: duplicate receipts are logged as `event_rejections(code='duplicate')` (excluded from "rejected"); unknown payload keys are computed at query time (v2 lab events, `json_each`); the Kiwi chat mode (`nativeTutoringMode/Source`) is kept in process memory per class and refreshed on every metadata pass (null after a server restart until the next sync, which the provider runs on any teacher page).
4. **Rebuild backups.** `sessions-v3` and `legacy-rejudge:<JUDGING_VERSION>` run from `telemetry.init` via `own_rebuilds()` (dynamic tag), not `DERIVED_REBUILDS`. They call `migrations.backup_once(tag)` unless this process already backed up the database (the pre-migration backup of the same start-up): FOUNDATION-10 asserts exactly one backup per migrated snapshot. A database without events records `<tag>:empty` instead of running (FOUNDATION-10a expects no backup; FOUNDATION-15 needs the plain `sessions-v3` tag free); `telemetry.rebuild_done(db, tag)` accepts either marker.
5. **Index scope.** `page_view`, `visibility`, `idle` and `telemetry_gap` are stored but do not open question activities (like heartbeats). Homework submissions get `kind='submission'` and one activity per attempt (`attempt-n` in the thread slot of the key). Native rows use `m:<materialId>` in the unit slot so a chapter mapping does not split activities. New counters `actions`, `telemetryEvents`, `clientChecked`, `clientCorrect` are kept out of `COUNTERS` (v0.5.1-shaped SQL keeps working). Client-reported server-owned events (`_clientReported`) never count as attempts.
6. **Server-written events** skip payload type validation (P2: a server event is never lost to a type mismatch); unknown types still raise; truncation applies.
7. **Workspace attribution** is `attribution: {chapter: "selected"|"unattributed"}` (the registry types `code_run.attribution` as an object); unattributed runs get `unitId=''`.
8. **Plots** use the regular `webr::canvas` device and the output queue (frames composited per page): `captureR({captureGraphics})` throws without cross-origin isolation (PostMessage channel, our Vite server). Plots display at 504 px.
9. **Data health details:** client-gap periods carry an extra `browsers` count; `aiTurns.mismatch` counts v0.6 turns (`surface != 'legacy'`) without an analytics event; `legacyChecks` is not range-filtered; `retentionDue` keys are `events`, `chatTurns`, `submissions`; the route needs `viewInsights` and is audited as `analytics`.
10. **Bridge import:** the roster metadata pass is authoritative (records only create a roster row when none with `source='kiwi'` exists); students first seen through the activity stream, and everyone on the first sync, are marked backfilled; per-user backfill runs only for roster members first seen later (≤ 5 pages per sync call, shared with the main stream). A projection-version change backs up as `native-projection-v3` before the re-projection (when native events exist).
11. **Dev only:** React StrictMode mounts the telemetry root twice, so dev pages log two initial `page_view`s. Keepalive sends at `pagehide` can produce duplicate deliveries that the server ignores and Data health reports (at-least-once delivery, exactly-once storage).
12. `frontend.mjs` honors `KIWI_UI_DIR` (temporary copies); `LabRRuntime.ts` is copied unchanged (the old `captureGraphics` string replace no longer applies). `verify-integration.mjs` writes `.local/v0.6-integration-check.json`.
